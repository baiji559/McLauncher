# 界面排版优化

保留深色侧栏与主世界背景，调整列表、排版和控件层次。

- **视觉对齐**：版本行使用固定的 40px 图标区、16px 图文间距和独立箭头区。图标、文字组和箭头垂直居中，左右内边距为 16px。所有页面的主内容统一从左侧 36px 开始。
- **等宽排版**：版本名、内存、用户名、文件名、目录和日志使用 Cascadia Mono / Consolas，并保留中文字体回退。数字启用 tabular / lining 排版。中文正文统一字形和行高。
- **同心圆角**：列表外层圆角为 20px，内层版本行圆角为 12px，间距为 8px。下拉菜单外层 12px，选项 8px，间距 4px。输入框与操作按钮使用 8px 圆角。
- **标题换行**：按实际字体和可用宽度计算两行标题，优先在单词边界分行，并尽量平衡两行长度；支持中文和 Unicode 字符。短版本号不换行，完整名称保留在提示中，原始版本标识不变。
- **阴影与层次**：主卡片、版本列表、按钮、输入框和菜单去除常驻描边，改用背景色差和轻阴影。阴影绘制在独立背景层，文字保持清晰。键盘焦点仍有可见轮廓。
- **控件高度**：输入框、下拉框和普通按钮统一为 40px；取消输入框模板中重复的内边距。

验证包括五页导航、版本选择、账号模式、资源筛选、内存绑定和大小窗口渲染，以及长版本名的两行排版。界面测试读取独立测试目录，不修改用户的游戏文件。

当前独立 EXE：`artifacts/standalone/McLauncher.App.exe`；已安装 .NET 10 Desktop Runtime 时可使用更小的 `artifacts/lightweight/McLauncher.App.exe`。历史构建产物已清理。
