# 2026-10-28 代码精简与占用优化

基线为 `MCLauncher-source-2026-10-28-ui-refined.zip`，其 49 个文件在修改前与工作区逐个 SHA-256 核对一致。

## 改动

- PortableMC 运行期间不再累积全部事件。查询只保留需要返回的行，日志实时交付；失败时异常保留最后一条结构化错误，缺少结构化错误时使用最后一行 stderr。界面仍保留最近 1000 行日志。
- 删除未使用的 `PortableMcResult`、事件原始行副本、版本频道、账号显示属性和分页结果中的页大小。保留实际绑定和调用使用的成员。
- Modrinth 先按日期和主文件顺序分页，再为当前页创建文件对象，避免为所有历史文件创建显示字符串和业务对象。
- 下载只计算平台实际提供的哈希，关闭 FileStream 的额外缓冲，继续使用原有传输缓冲和长度、哈希校验。
- 切换版本仅刷新对应模组，避免重读全部版本 JSON；安装完成、游戏退出、目录变化和窗口激活时刷新完整本地列表。初始化、刷新和登录只在入口解析一次游戏目录，内部传递已解析的目录。删除重复的忙碌检查和属性通知。
- 构建时用 .NET SDK 自带的 `ZipDirectory` 压缩内嵌后端。程序流式解压，后端版本、许可证和原始 EXE 的 SHA-256 保持一致。生成的 ZIP 位于 `obj/`，由构建任务重新生成。
- 删除构建及运行未引用的后端 PDB。清理工作区历史发布、编译中间文件和本地 .NET 缓存，保留原始源码压缩包、字体备份和两种当前发布版。

## 测量

| 项目 | 原版 | 修改后 |
| --- | ---: | ---: |
| 5000 个 Modrinth 版本取一页 20 个文件，平均托管内存分配 | 11,035,984 字节/请求 | 3,452,573 字节/请求 |
| 内嵌后端 EXE 与许可说明 | 9,514,220 字节 | 4,122,973 字节 |
| 轻量单文件 EXE | 12,361,856 字节 | 6,977,152 字节 |
| 自带运行时的独立 EXE（旧 standalone 对照） | 71,316,210 字节 | 71,616,049 字节 |

分页场景分配减少约 69%，轻量 EXE 减少约 44%。分页数据来自固定 JSON，通过真实 `ContentCatalogClient` 实现解析；预热 3 次后测量 3 次平均值。这是指定场景的托管分配量，不代表整个程序的常驻内存降幅。

独立版的单文件压缩会再次压缩内嵌 ZIP，体积比旧 standalone 增加约 0.29 MiB，当前约 68.3 MiB。轻量版省去随附运行时，需要电脑已安装 .NET 10 Desktop Runtime。
